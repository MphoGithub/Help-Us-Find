# Help Us Find

HelpUsFind is a free web application that lets you create a missing person or missing pet poster in a matter of minutes. 
No design skills needed, all you have to do is fill in the form and the poster is updated as you type, so you can spot mistakes before you download it.

## Why I Built This
When a loved one goes missing, every second counts. A poster, when created and shared quickly, can help people know who or what to be on the lookout for.
HelpUsFind lets anyone make a clear, print-ready poster without any design skills.

## Features
* **Two poster types**: missing person or missing pet, each with its own fields
* **Live preview**: the poster updates as you type, so you can spot mistakes before you download
* **Photo upload**: add a clear photo of the person or pet
* **Choice of headlines**: for example "MISSING" or "HAVE YOU SEEN THIS PERSON?"
* **Last seen details**: date, time, location and circumstances
* **Optional vehicle details**: make, model, colour and plate number
* **Two download formats**: PNG (to share online) and PDF (to print on A4)
* **Private by design**: photos and details stay in your browser. Nothing is uploaded to a server.

## How it works:

1. Choose missing person or missing pet
2. Fill in the details.
3. Upload a clear photo
4. Download the poster as a PNG (image) or PDF.

## Built with
* React 18
* Vite 5
* Tailwind CSS 3
* html-to-image to turn the poster into an image
* jsPDF to create the PDF

## How this was made

I built this app with the help of AI. I gave Cursor and Claude (free tier) prompts describing the form, features and design I wanted. 
I then improved the design and some of the code myself.

HelpUsFind helps with awareness. Please also report a missing person to the police.
